# ADR-0005: Публичные import paths сохраняются при внутреннем упрощении

**Статус:** Accepted  
**Дата:** 2026-07-27

## Контекст

В репозитории есть `interfaces.py`, `repositories.py`, пустые service/task-модули и мелкие selector-обёртки. Аудит показал, что ряд интерфейсов не имеет first-party consumers, часть репозиториев дублирует ORM selector, а один task/service цикл создан через локальные импорты. Однако такие пути могут быть динамически использованы Django Admin, Celery autodiscovery, management commands или внешними интеграциями; их удаление по одному `rg` небезопасно.

## Решение

Упрощать структуру только через compatibility-first migration:

1. зафиксировать current API/import path и characterization tests;
2. создать новый owning API там, где это действительно нужно;
3. оставить старый путь как тонкий re-export/deprecation shim без логики;
4. мигрировать first-party consumers и проверить dynamic registrations;
5. удалить shim только после согласованного периода, поиска consumers и отдельной проверки release notes.

Новые generic interface/repository/policy files запрещены без документированного consumer и инварианта. Сохранение compat не означает сохранение старой архитектуры навсегда.

## Последствия

Положительные:

* рефакторинг не ломает скрытые imports и entrypoints;
* можно удалить преждевременные абстракции по доказательству, а не по впечатлению;
* future contributors получают ясное правило, где помещать новую логику.

Ограничения:

* временно существуют тонкие shims;
* каждое удаление требует inventory dynamic consumers, а не только статического поиска;
* deprecation deadline должен быть виден в roadmap/release documentation.

## Область и проверка

Применяется к любому переносу/удалению Python module, selector/service/repository/interface и Celery task import. Перед удалением выполняются static import search, Django app/admin checks, Celery registration check и targeted tests. В audit finding должен быть отмечен confidence и не допускается automatic deletion при `AMBIGUOUS_PRODUCT_DECISION` или неясном external consumer.
