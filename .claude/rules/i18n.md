# Тексты для людей и языки (PQ-040)

Подробно: `docs/architecture/LANGUAGES.md`. Полноту каталогов проверяет
`tests/core/test_i18n_catalog.py`, подписи Admin — `tests/core/test_admin_language.py`.

- По умолчанию украинский; готовые тексты uk/ru/en. Владелец выбирает
  основной и включённые языки гостей и может заменить любой текст гостя на
  каждом языке (`BotText`). Гость — язык Telegram или выбор в профиле;
  персонал и Admin — свой язык (`User.language`, переключатель в шапке Admin),
  по умолчанию — язык платформы `uk`.
- Текст пишется в коде по-русски внутри `_()` из `core/i18n.py`, значения —
  параметрами: `_("Сумма: {total} грн", total=...)`. Переводы на украинский и
  английский — в `locale/{uk,en}/LC_MESSAGES/django.po`:
  `python3 infrastructure/scripts/messages.py update`, перевести,
  `python3 infrastructure/scripts/messages.py compile`.
- Подписи, вычисляемые при импорте (`verbose_name`, `choices`,
  `@admin.display`, `fieldsets`), — `gettext_lazy as _lazy`. У новых полей и
  вариантов — `verbose_name` и подписи по-русски.
- В шаблонах — `{% load botera_i18n %}{% tr "…" %}`. Строки темы Admin —
  `locale/<язык>/LC_MESSAGES/theme.po`.
- Текст для другого человека (уведомление) — внутри
  `speaking_to_employee(...)` / `speaking_to_guest(...)`: на языке получателя.
- `_` не использовать как переменную (`_unused`).
