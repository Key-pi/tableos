# Документация

- Пишется по-русски. Код упоминается как `path` или `path:symbol`, без номеров
  строк; Admin — путём меню, как его видит заведение («Настройки» →
  «Настройки бота»).
- Обновлять в том же коммите, что и код: `docs/architecture/AS_IS_ARCHITECTURE.md`,
  `docs/product/FEATURE_MATRIX.md` (и дату сверки в его шапке), PQ/ADR при
  решении владельца, документ своей области, строку журнала в
  `docs/engineering/TESTING.md` (что сделано, тесты, мутации, итог прогонов).
- Число тестов — только в `TESTING.md` (шапка и журнал) и в цифрах по коду
  `AS_IS_ARCHITECTURE.md`; в инструкциях его не повторять.
- Решение владельца — строка PQ в `docs/product/OPEN_PRODUCT_QUESTIONS.md`
  (таблица из пяти ячеек) со словом «Утверждено <дата>». ADR не переписывать:
  дописывать датированное «Уточнение».
- Не править исторические снимки: `docs/audits/BASELINE.md`,
  `AUDIT_SUMMARY.md`, `CODEBASE_INVENTORY.md`, `FILE_COVERAGE.md`, доказательства
  находок AA-001–AA-050, `TABLEOS_TZ.md`. Новая находка — новый номер AA в
  `ARCHITECTURE_AUDIT.md` и строка в «Остаются открытыми».
- После проверки владельцем и слияния ветки: «Где мы сейчас» в `CLAUDE.md`,
  строка в `docs/audits/REFACTOR_ROADMAP.md` («После дорожной карты»), статус
  в PQ.
- Инструкции для Claude: `CLAUDE.md` — то, что нужно в каждой сессии и
  должно пережить сжатие разговора, короче 200 строк; решение по одной
  области кода — в `.claude/rules/<область>.md` (поле `paths:`; после сжатия
  вернётся, только когда снова откроют файл области); процедура по шагам —
  в навык `.claude/skills/tableos-development/SKILL.md`, главное — вверху
  (после сжатия остаётся начало). Правило, которое владелец дал в разговоре
  на будущее, — записать туда же, иначе оно потеряется после сжатия.
- Без настоящих токенов, паролей, ключей и Telegram ID — только заглушки.
- То, что должно выполняться всегда, без исключений, — не текстом, а в
  `.claude/settings.json`: запреты (`permissions.deny`) и хуки. Держать их
  мало; каждое изменение — с согласия владельца, оно действует на всех, кто
  работает в репозитории.
