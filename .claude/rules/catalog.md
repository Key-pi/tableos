# Каталог (PQ-049)

Подробно: `docs/architecture/CATALOG.md`. Импорт (Excel/CSV) отложен до
решения владельца.

- **Структура:** подкатегории — два уровня; расписание категории — вне времени
  видна, но не продаётся (проверка на сервере `first_not_on_sale`, быструю
  продажу не ограничивает); метки — готовые и свои; витрина — модуль
  `module_showcase_enabled`.
- **Варианты и добавки** — модуль `module_options_enabled`: варианты — один
  список со своей ценой, добавки — общие группы на позициях или категориях,
  вес — фасовками, быстрая продажа — с выбором. Что выбрано и сколько стоит —
  только `apps/menu/options.py:resolve_choice`; выбор — в имени и цене строки
  заказа, при оформлении проверяется заново.
- **Остатки** — модуль `module_stock_enabled` (позиции с `track_stock`): заказ
  списывает при оформлении, отмена возвращает; гость видит «нет в наличии» /
  «осталось мало», без числа; быстрая продажа списывает и может уйти ниже
  нуля; возврат кладёт на склад только с отметкой персонала. Всё — через
  `apps/menu/stock.py` с записью `StockMovement`; Admin пишет остаток только
  пересчётом (`count_stock`). Блокировки — `locks.md`.
- **Переводы каталога:** языки — те же uk/ru/en; владелец переводит в Admin
  (`translations` у моделей каталога, поля — для включённых языков гостей,
  кроме основного); гость видит перевод (`translated`), без перевода —
  оригинал; строка заказа хранит имя на основном языке для персонала, экраны
  гостя строят его заново (`line_names_in`, без запросов).
