# Бот (aiogram)

Подробно: `docs/architecture/BOT_RUNTIME.md` (порядок роутеров, callback-и).

- Сообщения — в HTML; каждое динамическое значение (партнёр, меню, гость,
  сотрудник, комментарий) — через `bot/utils/html.py:escape_html`.
- `callback_data` ≤ 64 байт: UUID — в виде hex, состояние шагов — в самом
  callback (без FSM, где можно).
- **Сервис ботов (PQ-041, PQ-042):** в работе боты запускает
  `bot/supervisor.py:BotSupervisor`; неисправный бот не мешает остальным, его
  причина — в `BotInstance.runtime_state` (Admin → Боты, «Состояние»);
  список перечитывается раз в минуту без перезапуска; «Unauthorized»
  останавливает только этот бот до смены токена. `bot/main.py:run_polling` —
  только для эмулятора и нагрузочного теста.
- **Путь гостя (PQ-043):** без выбранного способа меню только для просмотра
  (без «➕»), под ним кнопки способов (`pick:<способ>`); за столом кнопок
  удалённых способов нет; после /start — короткое приветствие и «Как хотите
  заказать?».
- **Экраны персонала (PQ-044):** кнопка «Рабочий режим», списки со страницами,
  «Иду» на вызове.
- Обработчики — адаптеры: действие идёт через сервис владельца, как и в Mini
  App и Admin; правило не повторять в обработчике.
