# Каналы заказа: самовывоз, доставка, отправка почтой

Подробно: ADR-0009, `docs/architecture/PICKUP.md`, `DELIVERY.md`,
`SHIPPING.md`, `PAYMENT_OPTIONS.md`.

- **Конструктор (PQ-033):** владелец включает варианты, гость выбирает из
  включённых; не зашивать один вариант в канал. Оплата удалённых заказов —
  «переводом заранее» и/или «при получении», на модуль
  (`Order.payment_timing`). Новый модуль — с тестом, что он работает один и
  что его настройки и выключение не задевают остальные
  (`tests/apps/billing/test_shipping.py:ModuleIndependenceTests`).
- **Самовывоз:** перевод на реквизиты заведения (подтверждает
  владелец/менеджер/кассир) и/или оплата на месте, бонусы по желанию,
  телефон обязателен, только в часы работы (`OpeningHours`).
- **Доставка (PQ-032):** то же, что самовывоз, плюс адрес (текст обязателен,
  геолокация по желанию, последний запоминается); цена — фикс, бесплатно от
  суммы, минимальный заказ; цена — строка заказа
  `OrderItem.kind = delivery_fee` без позиции меню; персонал отмечает «в
  пути» и «доставлено». Оплата при получении и «гость не забрал» — только со
  статуса «в пути»; если «Доставлено» нажали раньше денег, оплату можно
  отметить и у завершённого (PQ-044).
- **Отправка почтой (PQ-034):** службы без API (Нова Пошта, Укрпошта, Meest —
  какие включил владелец), отделение или почтомат текстом, последний
  получатель запоминается; пересылка — по тарифу перевозчика и/или фикс в
  заказе (строка `delivery_fee` «Пересылка»), гость выбирает; оплата —
  перевод и/или наложенный платёж (`Payment.Method.COD`, только у
  отправленной посылки); без ТТН заказ не «отправлен» (`mark_order_shipped`);
  «Получен» — гость или персонал; без часов работы.
- **Неоплаченные заказы (PQ-036):** лимит открытых неоплаченных удалённых
  заказов на гостя (`remote_unpaid_orders_limit`, 2) и автоотмена
  неподтверждённого перевода (`transfer_wait_minutes`, 60; beat
  `billing.cancel_expired_transfer_orders`).
- **Часы и уведомления (PQ-038):** свои часы у самовывоза и доставки
  (`OpeningHours.scope`, без своих — общие); сотрудник выбирает способы
  заказа для уведомлений (`notify_channel_*`). Реквизиты общие.
- Стоп-лист при оформлении за столом не перепроверяется (AA-051) — чинить
  только после решения владельца.
